# Augur

Compagnon pour League of Legends sur Windows : profil et historique, aide à la sélection des champions, écran de chargement et overlay en partie.

Augur est en **bêta fermée**. Ce dépôt ne contient que les installeurs et les fichiers de mise à jour ; le code source n'est pas public.

## Installer

1. Ouvrez la dernière version « Augur Beta » dans l'onglet *Releases*.
2. Téléchargez `Augur-Beta_<version>_x64-setup.exe` et lancez-le (aucun droit administrateur requis).
3. L'application se met à jour d'elle-même ensuite.

Windows 10 ou 11, avec WebView2.
